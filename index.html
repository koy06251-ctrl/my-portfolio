Deploying to Vercel (.vercel.app)

1-Click & GitHub Step-by-Step Guide

You can host this entire single-file portfolio on Vercel with a custom *.vercel.app URL in less than 2 minutes for free:

  1. Step 1: Save the File Save this code file locally as index.html inside a new folder.
  2. Step 2: Push to GitHub Create a new repository on GitHub named portfolio and commit index.html.
  3. Step 3: Connect to Vercel Go to Vercel.com, log in with GitHub, click "Add New Project", and import your portfolio repo.
  4. Step 4: Deploy! Click "Deploy" without changing any settings. Vercel will instantly generate your live domain (e.g. jericho-rendon.vercel.app).
